# Siena Detection LecTrace presentation

This repository publishes the approved, prebuilt static LecTrace presentation for the Siena Seizure Detection course project.

It contains only the browser assets required to view the presentation: `index.html`, bundled assets, and the frozen presentation trace. It does not contain EEG recordings, training code, model checkpoints, or private project files.

Open the GitHub Pages URL shown in the repository's About/Pages settings. The presentation runs entirely in the browser and requires no download or installation.

The presentation has 15 navigation steps and five execution states. Its displayed calculations, figures, and evaluation results are frozen from the approved local presentation build.

## Static deployment notes

- The site is published from the repository root.
- Asset and trace references are relative, so it is compatible with the `/siena-lectrace/` GitHub Pages subpath.
- `.nojekyll` disables Jekyll processing and preserves the generated static site exactly.
